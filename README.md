# smart-portfolio-core

Sistema de gestión y análisis de portafolios de inversión desarrollado como proyecto del Seminario de Programación - Business Intelligence.

## Descripción

Aplicación en Python que permite gestionar un portafolio de instrumentos financieros, consultar datos de mercado en tiempo real y generar reportes de rendimiento. Implementa patrones de diseño, validación con Pydantic, programación asíncrona y una API REST con FastAPI.

## Funcionalidades

- Modelado de instrumentos financieros y posiciones con dataclasses
- Generación de reportes en CSV, JSON y HTML
- Consulta de precios en tiempo real via Yahoo Finance
- CLI interactivo para análisis del portafolio
- Validación de datos con Pydantic
- Consultas asíncronas con asyncio
- API REST con FastAPI
